THE IDEA

A process has structure.

ProcessGAT converts each observed case prefix into a directed graph. Activities become nodes; directly-following relationships become edges with transition information. Graph attention then learns how that context relates to the next activity.

The architecture is deliberately compact: graph representation, multi-head attention, residual learning and graph-level prediction.

GRAPH REPRESENTATION

Activities become nodes.

Each prefix is represented as a directed graph. Six normalized node features encode activity identity and process context, while transition information is carried through edge attributes.
