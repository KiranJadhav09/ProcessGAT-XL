MODEL

Graph attention
for process structure.

ProcessGAT-XL combines graph representation, multi-head GATv2 attention, residual learning and graph-level pooling.

PROCESSGAT-XL

One model.
Several views of context.

Each prefix graph enters three residual attention blocks. The resulting node representations are aggregated with learned graph attention and global pooling before six-class classification.

Parameters190,895
GATv2 layers3 residual blocks
Attention8 heads
Hidden64
Edge dimension8
